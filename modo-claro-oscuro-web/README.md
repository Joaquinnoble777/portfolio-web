# Modo Claro y Oscuro para Página Web

Este proyecto implementa un sistema de cambio de tema entre modo claro y oscuro en una página web. A continuación se detallan los archivos y su propósito.

## Estructura del Proyecto

```
modo-claro-oscuro-web
├── src
│   ├── index.html          # Estructura principal de la página web
│   ├── css
│   │   └── styles.css      # Estilos para modo claro y oscuro
│   ├── js
│   │   └── theme-toggle.js  # Lógica para alternar entre temas
│   └── assets              # Recursos como imágenes e iconos
└── README.md               # Documentación del proyecto
```

## Instalación

1. Clona este repositorio en tu máquina local.
2. Abre el archivo `src/index.html` en tu navegador para ver la página en modo claro por defecto.

## Uso

- Para alternar entre el modo claro y oscuro, simplemente haz clic en el botón de cambio de tema que se encuentra en la parte superior de la página.
- La preferencia de tema se guarda en el almacenamiento local del navegador, por lo que se mantendrá incluso si recargas la página o cierras el navegador.
